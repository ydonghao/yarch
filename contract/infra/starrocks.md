# StarRocks 开发规约（v1.0 已定稿）

> **状态：已定稿**（2026-09-01 评审通过）。供人阅读、供 AI 作为规范上下文使用。
> 等级：**【强制】**违反即缺陷；**【推荐】**默认遵守、评审后可豁免；**【参考】**正向引导。适用 StarRocks 3.x。分工与来源见文末附录。

## 一、定位与分工

1. 【强制】StarRocks 只做 OLAP/实时数仓：交互式 BI 报表、多维分析、实时明细与汇总；OLTP 归 PG/MySQL。
2. 【强制】OLAP 双引擎分工（已落决策，可推翻）：**StarRocks 管业务实时数仓与交互式 BI（默认 OLAP 引擎）**；ClickHouse 管日志与遥测事件流分析（见 [clickhouse.md](clickhouse.md) 一-2）。同数据域不双写，需评审。
3. 【强制】库名 = 数据域/服务名（`dwd_trade`、`dws_trade` 数仓分层命名按团队模型登记），共享集群按库授权隔离。

## 二、表模型与分桶

1. 【强制】表模型按读写语义选：**明细模型 Duplicate**（日志明细、无需更新）、**主键模型 Primary Key**（实时 upsert、点查与部分列更新）、**聚合模型 Aggregate**（固定维度汇总）；选型在建表评审记录理由。
2. 【强制】分区键按时间（`date_trunc` 日/月），分桶键选高基数等值查询列（用户 ID/订单 ID）；**单 tablet 目标 1~10GB，bucket 数按 `数据量/5GB` 起步**，禁过度分桶（小文件）与单桶过大。
3. 【强制】分桶键与高频查询条件对齐；广播 JOIN 的小维表可用 Colocate Group（按需评审）。
4. 【强制】排序键（DUPLICATE/主键的 sort key）= 核心过滤维度前置，建表期定妥。
5. 【推荐】更新频度高且需 latest 语义用主键模型 + partial update；实时链路（CDC）默认主键模型。

## 三、导入

1. 【强制】实时导入：Routine Load（Kafka，消费组命名对齐 [kafka.md](kafka.md) 四-1）或 Flink/Spark connector；批量导入：Stream Load / Broker Load——导入通道与数据域登记。
2. 【强制】导入攒批：Stream Load 单批 MB~百 MB 级，禁逐条/高频小导入（版本合并压力）；Routine Load 配置批大小与间隔。
3. 【强制】导入幂等与监控：失败重试、脏数据处理（error log 表）与积压告警；数据延迟 SLA 明确（分钟级实时 vs 小时级批量）。
4. 【推荐】schema change（加列）在低峰执行；大表列变更走影子验证。

## 四、查询

1. 【强制】查询显式列清单，禁 `SELECT *`；BI 语义层收敛维度与指标口径（指标定义有唯一出处）。
2. 【强制】交互式查询必须有超时与内存限制（`query_timeout`、exec mem limit），大查询路由独立资源组。
3. 【强制】高并发点查走主键模型 + 行存缓存（按需开持久化索引）；禁明细大表裸点查。
4. 【推荐】热点报表用同步物化视图自动改写；跨域大 JOIN 用异步物化视图预计算。

## 五、数据生命周期

1. 【强制】分区 TTL/过期策略显式（动态分区 `dynamic_partition` 按天/月滚动），保留期登记；冷热分层存储按成本评审。
2. 【推荐】明细与汇总分层（ODS/DWD/DWS）：明细可缩短保留，汇总层长保留——以物化视图/调度任务维护。

## 六、运维基线

1. 【强制】生产 FE ≥3（高可用）+ BE ≥3；存算一体起步，湖仓/存算分离（CN）按需评审。
2. 【强制】监控：导入延迟与失败、compaction（版本数/得分）、查询超时率与 P99、BE 磁盘水位（70% 治理）、tablet 不健康。
3. 【强制】备份：关键汇总表快照/导出（含元数据），恢复演练季度化；明细可由源头重放时以源头为准（与 [kafka.md](kafka.md) 六-5 同口径）。
4. 【推荐】资源隔离：导入与查询、批量与交互式分资源组，防互相饿死。

## 附：分工与来源

- **OLAP 分工（已落决策，可推翻）**：StarRocks=业务实时数仓与交互式 BI（重叠场景默认）；ClickHouse=日志/遥测。理由：StarRocks 主键模型 upsert/点查/多表 JOIN 与 BI 兼容性更强；CH 摄入链路与日志生态成熟。
- 表模型选择、tablet 1~10GB/bucket 5GB 起步、动态分区、主键点查：StarRocks 官方文档建表最佳实践。
